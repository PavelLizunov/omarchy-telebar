# Native consumer review — 2026-09-30

Candidate: dirty worktree based on `b5148935089cc430d93157caed2d0eec51ef84d9`.
Plugin: `reidenxerx.omagram`. Qt 6.11.2, Omarchy 4.0.4.
Render origin: actual QML consumers with inert, explicitly synthetic data; DPR 1,
software renderer. No production account content in images. Palette is the fixture
and existing adapter palette, not proof of every desktop theme.

## Results by evidence surface

- Rendering: actual app content consumers rendered through QML-preview MCP.
- Image inspection: listed final PNGs below read through the harness and inspected.
- Native design: reviewed hierarchy, message boundaries, wrapping, field/control fit,
  compact sidebar, readable state feedback. Fixed concrete defects; not a usability study.
- Anti-slop: original functional icons, finite state animation, no decorative glows,
  fake service metrics or marketing copy. Synthetic contents labelled as fixtures.
- Interaction: QML consumer tests exercise settings load/Escape, menu keyboard selection
  and dismissal, forum selection, QR/phone/password transitions; morph test verifies
  intermediate/settled geometry and disabled motion. Other actions remain unexercised.
- Runtime: installed window loaded; private IPC `app.quit` delivered quit then ack,
  window exited and daemon completed its graceful close. No logout/data deletion.
- Not verified: full bar PopupCard/PanelWindow rendering, all dialogs/routes, all locales,
  light themes, accessibility consumers, camera and video/GPU playback. Bar render failed
  because `Quickshell.Hyprland` is unavailable in the legacy render adapter.

## Tool capability limitations

The installed MCP advertises only `render_qml`, schema: qmlPath/outputPath/width/height.
`ping` succeeded; `healthcheck` returned tool-not-found. Fixed 300 ms render delay,
no explicit readiness/locale/DPR/measureObjects/dependencyPaths support. It is not the
newer preview contract. `Preview.ready` exists but the legacy tool does not wait for it.
No general visual PASS is inferred from a render call or warning-limited qmllint.

## Confirmed corrections

1. Ambiguous edit/pin/at/reply icons simplified; thicker rounded strokes.
2. Original play/pause and sidebar arrow have matched vector contours with 160 ms
   transitions; no per-frame SVG reparsing.
3. Chat bubbles separated with spacing, faint borders, rounded corners and higher fill.
4. Quick-reply background removed from the Column positioner's direct children; initial
   attempt caused overlapping text, rerender confirmed correction.
5. Settings explicitly load on construction, not only visible-change notifications.
6. Missing/malformed ping no longer displays NaN.
7. Boolean badge/pin/closed bindings explicitly guard undefined fixture values.
8. Quit no longer kills daemon before it receives the request. Quit event bypasses the
   UI backlog; shell suppresses restart and daemon closes every TDLib client.
